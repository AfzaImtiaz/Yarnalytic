# Yarnalytic
A crochet & knitting yarn calculator that compares pattern requirements with your yarn, estimates yardage, and suggests substitutions.

Ever found the perfect crochet or knitting pattern, only to realize you don't have the recommended yarn? Yarnlytics helps you figure out what to use instead and how much you'll need.

Enter the yarn requirements from an existing pattern and the specifications of your own yarn. YarnMate compares yarn weight, gauge, and yardage, then calculates an estimated amount of yarn required using gauge-based scaling. It can also suggest potential substitutions from a fixed yarn database.

To make things easier, users can upload a photo of their yarn label so key details such as weight, yardage, gauge, and hook size can be extracted instead of entered manually.

The goal: take the confusing yarn math out of crochet and knitting. No guessing, no manually comparing labels, and no discovering halfway through a project that you don't have enough yarn.

How it works:
Pattern → Extract/Enter Requirements → Add Your Yarn → Compare Gauges → Calculate Yardage → Find Substitutions

Built as a practical tool for crocheters and knitters who want to confidently use the yarn they already have.
